# CoAura

## Core Definition
CoAura is the renderable, AI-first interface envelope through which a CoObject is exposed to minds and systems.

## Principle
One CoObject → many rendered CoAuras (domains, apps, surfaces)

## Layers
- CoObject (truth, external repo)
- CoAura (render + UX)
- CoStacks (runtime/operator)
- CoClouds (pressure/context)

## Status
Seed v0 — projection-safe, non-canonical

## CoUX+ / CoSurface+ evolution intake

CoAura is an elected public projection/UX laboratory for **CoAura+**, **CoUX+**, **CoSurface+**, accessibility, AI-facing views, observer-relative rendering, and RickBar/CoDesktop-adjacent interface relations.

Capable sessions should use the shared [CoAll GitHub Evolution Fabric](https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md). Prefer reversible projection changes, explicit source/currentness pointers, and receiver-relative loss reporting over treating one UI as the object itself.
